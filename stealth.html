How to use this paper wallet

Receiving: Share the sv1… address with anyone who wants to send you VEIL privately.

Checking balance: You cannot check balance without importing the scan key into a Veil wallet.

Spending: Import both the scan and spend WIF keys into a Veil Core wallet using the debug console. Contact the Veil community for current import instructions.

Backup: Print this page or write down ALL THREE items: the address, scan WIF, and spend WIF. Store them securely and separately if possible.

Note: Veil stealth addresses are sv (main) / tps (test). This tool generates dual-key stealth addresses compatible with Veil's RingCT system.
